How the simulator works (one slide)

  1. Morning: deliveries arrive (order-up-to 1.2× expected demand; same rule for both policies).
  2. Price: each batch is priced by days to expiry using the rule.
  3. Shoppers: regular shoppers ~ Poisson(demand × weekday); discounts add bargain shoppers ~ Poisson(demand × weekday × sensitivity × discount).
  4. Choice: 50 % of regulars grab a markdown if there is one (cannibalisation); otherwise 60 % take the oldest unit, 40 % the freshest.
  5. Close: anything on its last day is thrown away at cost.
